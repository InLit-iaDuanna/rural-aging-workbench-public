# 乡筑 V2.0 实施交付状态

2026-09-10。本轮已修改源码、安装并锁定依赖，建立可本地运行的业务服务和 V2 工作区。六周仍是实际试点的目标周期，不是已完成现场工作的声明。

## 已实现

- 保留旧空间工作台，新入口提供档案、调试、方案工作区。
- 空间尺度分为未知、演示、人工标定、已核验；道路未知属性和未关联风险保留未知；共享空间计算不把经纬度直接当米。
- PostgreSQL 对象、项目角色、邀请认证、版本冲突、事务确认和操作记录；私有材料鉴权、授权撤回与关联失效。
- SurveyJS 四套采集表、Dexie 本地草稿与待同步队列、显式冲突处理、已访问页面离线缓存。
- LangGraph PostgreSQL 检查点、人工中断恢复、持久任务 worker；CodeBuddy/Codex 独立适配器、结构校验、超时取消与执行记录。
- XState 角色状态、六名合成角色、三情景、离散事件、时段/容量/连续步行规则、模型合法动作复核、保存决策回放。
- 证据录入和检索、草案、独立人工复核、幂等确认、行动分派、回访和现实版本更新。
- 腾讯 TMap 地理定位、服务端签名地址解析、固定上游代理；与影像空间分析分开。
- 容器配置、迁移、备份/恢复、合成示例、操作文档与验收脚本。

## 与原计划的差异和待交付

1. 独立生产主机及真实 HTTPS 地址未提供，当前业务服务、数据库及腾讯凭据运行在本机。Sites 前端发布不等于这些服务已上线。
2. 两个 CLI 的小规模调用均曾成功，但复杂 AI 整链出现格式失败和 120 秒超时，不能宣称稳定通过全部 AI 验收。失败保留，用户可明确重试。独立人工复核和业务确认依然是正式步骤。
3. 证据示例为三份待核验政策材料，没有把它们声明为已实施案例或已完成人工核验。
4. 角色/场景支持结构化配置与 JSON 导入，尚未形成所有参数的可视化编辑器。方案差异为显式变量、指标与记录展示。
5. 腾讯地图仅查询定位，不自动建立村庄配准或把查询结果写成现实事实。
6. 手机端离线体验、不同浏览器、真实多人现场使用和六周试点尚未完成。待办与记录模板见 PILOT_RECORD.md。
