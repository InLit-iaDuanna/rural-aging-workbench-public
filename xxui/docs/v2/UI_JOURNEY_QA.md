# 本地用户旅程验收 · 2026-09-10

本轮目标：紧凑入口、首次指引、真实村庄初始化、真实 AI 分析及结果恢复。使用浏览器实际操作 localhost:3000；测试村庄命名为“宏村 · 流程体验”，不代表现场试点。

- 登录后查询安徽省黄山市黟县宏村，腾讯地图显示实际底图和查询位置。
- 确认位置创建档案，自动进入初始化。
- 保存目标、范围、步行通行与助餐服务关注项，自动进入分析。
- 点击开始分析，观察 CodeBuddy 执行、独立复核，最终自动进入结果页，显示需补充资料。
- 点击导出按钮；结果历史可以重新打开。
- 刷新页面后，从已有村庄重新进入，初始化目标、范围和关注项保持。
- 浏览器截图核对 687px 宽窗口：四步导航、表单和主要按钮无横向裁切。
- 数据库集成测试新增初始化持久化、版本冲突、录入角色拒绝修改与不捏造路网的断言。
- 19 项测试通过；TypeScript 检查、生产构建通过。

## Limitations

此次验证覆盖初始化与咨询旅程，不代表六周现场试点完成。真实道路与设施仍需采集；AI 回复为辅助建议，复核意见需一并阅读。部署验证范围为本机。
